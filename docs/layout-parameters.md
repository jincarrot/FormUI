# 布局与参数约定

下拉菜单展开后覆盖其他控件，其他控件仍按 `grids` 的行列位置排列。滚动内容高度取正常布局高度与菜单实际底边中的较大值。选中、切换或隐藏菜单后重新计算高度；Group 中的菜单会累计各级父组的位移。

下拉菜单的 `items` 为静态选项列表：每项的 `label` 是字符串，`value` 是整数或字符串，两者均不接受 Observable。菜单标题和选中值仍支持 Observable。添加控件时复制选项，修改原始列表不会改变已添加的菜单。

表单根控件的 `width`、`height`、`offsetX`、`offsetY` 支持通过 Observable 设置为 `"default"`，恢复创建时记录的原生布局。根控件的新尺寸或位移会替换此前尚未完成的过渡。

## 显示、关闭与追加控件

`show()` 会检查本次目标玩家。同一玩家已经在显示该表单（包括等待创建的阶段）时，再次调用会抛出 `RuntimeError`，提示“该表单已经被显示出来了”。检查失败时不会发送新表单或增加关闭监听。关闭后可再次显示；服务端可以分别向尚未显示的玩家调用 `show()`。

表单显示后仍可调用 `button()`、`label()`、`group()`、`custom()` 等添加方法。新控件同步到当前显示该表单的玩家，保留已有控件实例，并重新计算布局。表单尚未创建时，新控件加入待创建数据；在 `onCreate` 内追加的控件在本次创建结束后继续创建，并执行自己的创建回调。

创建期间调用 `close()` 会取消待显示任务和创建定时器，按 `api` 原因触发关闭回调。即使旧定时器已进入执行队列，也不会重新创建被关闭的表单或影响重新打开的实例。

## 字体大小

`form.label(text, {'fontSize': 1.5})` 设置字体缩放倍数，沿用网易原生 `SetTextFontSize` 的语义，不是像素字号。接受非负有限数值或 Observable；创建时的 `"default"` 保留模板设置，运行时设置为 `"default"` 将缩放恢复为 `1.0`。

```python
font_size = Observable.create(1.0)
form.label('可调整字号', {'fontSize': font_size})
font_size.setValue(1.5)
font_size.setValue('default')
```

原生接口语义见 [网易 SDK 的 SetTextFontSize 文档](https://github.com/MCNeteaseDevs/mc-netease-sdk/blob/main/1-ModAPI/%E6%8E%A5%E5%8F%A3/%E8%87%AA%E5%AE%9A%E4%B9%89UI/UI%E6%8E%A7%E4%BB%B6.md#settextfontsize)。

## 控件注册补发

客户端 UI 初始化完成后会向服务端请求已注册控件，服务端按当前注册表逐项补发。后来加入、重新连接的玩家会收到最新模板路径、完整的注册选项及 Group 定义的当前值。后续注册仍按原有广播流程同步。

## 滑动条

- `step=0`：连续模式。
- `step<0`：按其绝对值计算步长。
- `minValue>maxValue`：按数值大小排序边界；原始参数不变。
- 两端相等：固定在该值，原生滑动条百分比为零。
- 值和原生百分比超出范围时钳制到有效范围。
- 离散模式以较小边界为起点；较大边界不在步长网格上时，最后一个有效值为不超过它的最大步长值。
- 参数必须是有限数值；不接受布尔值、字符串、NaN 和无穷大。

Observable 修改边界或步长后，滑动条位置、数值标签和轮询缓存一起更新。此时只调整展示值，不主动改写绑定 Observable 中的原始值。

## 尺寸与位移

支持数值、像素字符串、百分比字符串以及由加减号连接的表达式。字符串可包含小数、负数和科学计数法；没有单位的数字按像素解释。

```python
"50.5%-2.25px"
"72.5%y+2px"
"-.5px"
"12.5"
"100%+-15px"
```

`%` 相对父控件当前轴，`%x` 和 `%y` 分别相对父控件的宽、高。同一表达式中的百分比须使用同一种参考轴。

`"fill"` 等价于 `"100%"`；`"default"` 使用原生默认值。空字符串、错误单位、尾随字符以及不同参考轴的混合百分比会抛出 `ValueError`。
